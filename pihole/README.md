# Pi-hole for Home Assistant

Run the **unmodified official `pihole/pihole` image** as a Home Assistant OS app.
DNS is available at your Home Assistant IP on TCP and UDP port 53. The admin
page is at `http://HOME_ASSISTANT_IP:4865/admin/`.

This app package is custom and is not endorsed or maintained by Pi-hole or Home
Assistant. Pi-hole itself comes directly from the Pi-hole project's registry.
See the **Documentation** tab for installation and router setup.
